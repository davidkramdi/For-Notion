Deux niveaux de type

Type 17 identifie l’enveloppe TCP Reliable Transport. À l’intérieur, Type 3 identifie le Map-Register classique. Ils sont tous les deux présents.

xTR / ETR— Type 17 Registration →Map-Server— Type 18 ACK ou Type 19 Rejected →xTR / ETR
Contraintes importantes : un seul Mapping-Record (Record Count=1) et T=0 sur Reliable Transport. Le Map-Register est transporté sans ses anciens en-têtes IP/UDP.
