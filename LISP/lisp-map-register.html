Les quatre éléments à ne pas mélanger

P, I et M sont dans l’en-tête du Map-Register. A est dans chaque EID-Record. Le xTR-ID n’est pas un bit : c’est un champ de 128 bits ajouté en fin de message lorsque I=1.

xTR / ETR— Map-Register (P, I, M, A) →Map-Server— si M=1 →Map-Notify
Lecture CCIE : P=proxy reply demandé au Map-Server ; I=identifiants présents ; M=accusé Map-Notify demandé ; A=Mapping-Record faisant autorité. Le R de l’en-tête est réservé, à 0 — ne pas le confondre avec le R du Locator-Record.
